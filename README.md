# 📌 로또

---
## 🧾 기능 요구 사항
### *"간단한 로또 발매기를 구현한다."*

> **로또 번호의 숫자 범위는 1~45까지이다.** <br>

> **1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.** <br>

> **당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.** <br>

> **당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.** <br>
>
> **1등: 6개 번호 일치 / 2,000,000,000원** <br>
> **2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원** <br>
> **3등: 5개 번호 일치 / 1,500,000원** <br>
> **4등: 4개 번호 일치 / 50,000원** <br>
> **5등: 3개 번호 일치 / 5,000원** <br>

> **로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.** <br>

> **로또 1장의 가격은 1,000원이다.** <br>

> **당첨 번호와 보너스 번호를 입력받는다.** <br>

> **사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.** <br>

> **사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.** <br>

> **Exception이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.** <br>

## 🖥️ 입출력 요구 사항

> ### 📥 입력
> - 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
> ```text
> 14000
> ```
>
> - 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.
> ```text
> 1,2,3,4,5,6
> ```
> 
> - 보너스 번호를 입력 받는다.
> ```text
> 7
> ```

> ### 📤 출력
> - 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.
> ```text
> 8개를 구매했습니다.
> [8, 21, 23, 41, 42, 43]
> [3, 5, 11, 16, 32, 38]
> [7, 11, 16, 35, 36, 44]
> [1, 8, 11, 31, 41, 42]
> [13, 14, 16, 38, 42, 45]
> [7, 11, 30, 40, 42, 43]
> [2, 13, 22, 32, 38, 45]
> [1, 3, 5, 14, 22, 45]
> ```
>
> - 당첨 내역을 출력한다.
> ```text
> 3개 일치 (5,000원) - 1개
> 4개 일치 (50,000원) - 0개
> 5개 일치 (1,500,000원) - 0개
> 5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
> 6개 일치 (2,000,000,000원) - 0개
> ```
>
> - 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
> ```text
> 총 수익률은 62.5%입니다.
> ```
> 
> - 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.
> ```text
> [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
> ```

> [1, 8, 11, 31, 41, 42]
> [13, 14, 16, 38, 42, 45]
> [7, 11, 30, 40, 42, 43]
> [2, 13, 22, 32, 38, 45]
> [1, 3, 5, 14, 22, 45]
>
> 당첨 번호를 입력해 주세요.
> 1,2,3,4,5,6
>
> 보너스 번호를 입력해 주세요.
> 7
>
> 당첨 통계

## 🧩 구현할 기능 목록

### 🟢 입력 관련
- "구입금액을 입력해 주세요." 문구를 보여주고 사용자 입력을 받는다.
- 입력받은 금액이 1000원 단위인지 확인한다. (1000원 단위가 아니면 예외)
- 구매 개수를 계산한다. 예: 8000 이면 8개
- "당첨 번호를 입력해 주세요." 문구를 보여주고 쉼표로 구분된 6개의 번호를 입력받는다.
- "보너스 번호를 입력해 주세요." 문구를 보여주고 1개의 번호를 입력받는다.

### 🟠 입력 검증 관련
- 금액은 0보다 커야 하고 1000원 단위여야 한다.
- 당첨 번호는 1~45 사이 정수 6개 중복이 없어야 한다.
- 보너스 번호도 1~45 사이 정수이며 당첨 번호와 겹치지 않아야 한다.
- 잘못된 입력 시 IllegalArgumentException을 발생시키고, [ERROR] 메시지를 출력한 뒤 해당 단계부터 다시 입력받는다.
 
### 🔵 로또 발행
- 입력한 금액으로 살 수 있는 만큼 로또를 생성한다.
- 한 장당 6개의 서로 다른 숫자를 1~45 범위에서 랜덤으로 뽑는다.
- 생성된 번호를 정렬해서 [1, 3, 5, 14, 22, 45]와 같은 형식으로 출력한다.
- "8개를 구매했습니다." 같이 구매 개수도 안내한다.

### 🟣 당첨 결과 계산
- 각 로또 번호를 당첨 번호와 비교해 일치하는 숫자의 개수를 구한다.
- 보너스 번호가 포함되어 있는지 추가로 확인한다.
- 일치 개수와 보너스 번호 여부에 따라 해당 로또의 당첨 구분과 상금을 결정한다.
- 같은 구분에 속하는 로또의 개수를 집계한다.

> 3개 일치 → 5,000원  
> 4개 일치 → 50,000원  
> 5개 일치 → 1,500,000원  
> 5개 + 보너스 일치 → 30,000,000원  
> 6개 일치 → 2,000,000,000원

### 🟤 수익률 계산
- 전체 상금 합계를 구한다.
- 수익률 = (총 상금 / 구입 금액) * 100
- 소수점 둘째 자리까지 반올림해서 퍼센트로 표시한다.

### ⚫ 출력
- '당첨 통계'와 구분선을 출력한다.
- 각 구분별 결과를 한 줄씩 보여준다.
- 마지막 줄에 총 수익률을 출력한다.

## ⚠️ 주의사항
- 들여쓰기(Indent) depth는 최대 2까지만 허용
- 3항 연산자(?:) 사용 금지
- else, switch/case 사용 금지
- 한 메서드는 한 가지 일만 하도록 구현할 것
- 메서드 길이는 15라인 이하로 유지할 것
- Enum 적극 활용
- UI 로직(System.out, System.in, Scanner)은 테스트에서 제외
- JUnit5 + AssertJ 사용
- 단위 테스트를 작성하여 기능이 정상 작동하는지 확인
- 예외 발생 시 assertThatThrownBy(), assertThrows() 등을 사용
- 테스트 대상은 비즈니스 로직만
- 입출력(Console)은 테스트하지 않기
- ParameterizedTest 활용해 반복 테스트 작성해도 좋음
- 제공된 Lotto 클래스는 반드시 사용
- numbers 외 필드 추가 금지
- numbers 접근 제어자(private) 수정 불가
- 패키지 이동은 가능
